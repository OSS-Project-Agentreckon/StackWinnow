# Security reporting

This is an unreleased student-maintained project; no supported security-release
window or response-time guarantee is established. Review planned changes and the
documented support limits before using it on sensitive projects.

For a suspected vulnerability, use GitHub's **Report a vulnerability** button on
this repository's Security tab if private reporting is enabled. If unavailable,
open a minimal issue asking a maintainer to enable private reporting; do not publish
exploit details, credentials, private paths or project content. Maintainers are
reachable through the [actual repository](https://github.com/OSS-Project-Agentreckon/StackWinnow).
No private reporting feature or security email is assumed to exist.

Include affected versions, OS/architecture, a minimal sanitized reproduction and
expected impact when a private channel is established. Normal functionality bugs
belong in public GitHub issues. Upstream tool/browser issues should also be reported
through those projects' own security channels.
